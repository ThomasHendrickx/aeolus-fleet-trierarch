# Decisions

Current state only; history is in git. To change a decision, edit its file and its line here in the same commit. Decisions keep one numbering across the trains' repositories; the full index is aeolus-fleet's [docs/decisions/README.md](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/decisions/README.md).

- [0026](0026-trierarch.md) **Trierarch.** A plain process per machine, crewing a ship of type trierarch with crew:run, a normal ship otherwise, commissioned by the trierarch plugin and set up with init; it reconciles from the crew requests assigned to it, crewing again a ship released elsewhere from a fresh worktree, writes their status and reports what it can do in its report's details; a spent restart budget writes crashed and reports to the ship's owner, argo as fallback; a session it crews holds no fleet credential, its calls forwarded over a socket of its ship's own with the crew token added, path and size checked, nothing queued; a new settings version (Restart, Edit) crews the ship again in its worktree; saved as crewing before register, so a lost register reply is released and crewed again; never picks, commissions or retires; a removed request is released and confirmed, removing its worktree whatever it holds and telling argo what that discards.
- [0039](0039-container-sessions.md) **Sessions in containers.** A machine's choice in its configuration (host by default), no crew setting or label, stated in the trierarch's details; the `SessionRuntime` port gets a container adapter, one container per ship with tmux inside; rootless Podman on Linux and Colima on macOS behind one adapter, never the runtime's socket inside, hard caps per session; the workspace a per-ship clone with `--reference` and `--dissociate`; no fleet credential in the container (its calls go over the trierarch's socket, 0026); one long-lived model token per machine, no Remote Control, Claude Code only; keys per repository; the image published with the release, another per repository built on it.
