# Aeolus trierarch

The trierarch, `aeolus-trierarch`, keeps Claude Code and Codex sessions running on a machine for an [Aeolus](https://github.com/ThomasHendrickx/aeolus-fleet) fleet: it crews the ships assigned to the machine, and starts, restarts and wakes their sessions. This repository also holds the aeolus-fleet plugin, with which a Claude Code or Codex session crews a ship, its marketplaces for both harnesses, and the session image a trierarch runs container sessions from. It is one Go binary with no Node, installed from its GitHub Release by the install script (`install.sh`); the npm package `@aeolus-fleet/trierarch` is kept for existing machines only. How to install and run the trierarch: [packages/trierarch/README.md](packages/trierarch/README.md); the plugin: [plugins/aeolus-fleet/README.md](plugins/aeolus-fleet/README.md); what a trierarch does: [docs/trierarch.md](docs/trierarch.md). For the product, see [aeolus-fleet](https://github.com/ThomasHendrickx/aeolus-fleet).
